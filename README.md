# iPhone 17 Pro Max — ინტერაქტიული 3D

iPhone 17 Pro Max-ის ინტერაქტიული 3D ვიზუალი ბრაუზერისთვის. აგებულია [Three.js](https://threejs.org/)-ით (r169), ერთ HTML ფაილში. გარე 3D მოდელი ან ტექსტურა არ გამოიყენება — მთელი გეომეტრია და მასალები კოდითაა შექმნილი.

## გაშვება

- **ონლაინ:** GitHub Pages-ის ჩართვის შემდეგ — `https://<username>.github.io/<repo>/`
- **ლოკალურად:** საქაღალდეში გაუშვით `npx serve .` ან `python -m http.server` და გახსენით მითითებული მისამართი.

საჭიროა ინტერნეტი — Three.js და შრიფტი CDN-დან იტვირთება. საჭიროა WebGL 2-ის მხარდაჭერა.
